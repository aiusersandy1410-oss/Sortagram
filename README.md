# Sortagram

A free, private, local-first tool for organizing saved Instagram/TikTok/etc.
reels and posts by topic and creator. No account required to use it.

**Live at: https://sortagram.vercel.app**

## Features

**Core organizing**
- Save links (Instagram, TikTok, Pinterest, YouTube, Facebook, X, or other)
  with title, thumbnail, and notes
- Auto-detects platform from the URL
- Organize by **topics** and **creators** — switchable view modes, or view both together
- Search across titles, notes, topics, and platform
- Light/dark theme toggle

**Import**
- Import from a JSON backup, or from an exported HTML file (e.g. a browser
  bookmarks/saved-posts export)
- Auto-tags imported items with the **creator** (detected from @username)
- Auto-tags with a **main topic** — Food, Tech, Fitness, Fashion, Travel,
  Home & DIY, Beauty, Money, Quotes
- Preview screen before importing — pick which items to bring in, and
  toggle creator/topic tagging on or off per import

**Data & privacy**
- Fully local-first — works offline, no account required
- Export a full JSON backup anytime
- "Clear all data" option

**Sync across devices** (optional)
- No email or password — just a shareable sync code
- Your data, your choice: sync is entirely opt-in
